# TaskCraft

TaskCraft is a personal workspace for turning study goals and project ideas into manageable next steps. It brings task planning, learning roadmaps, flashcards, progress tracking, and a study assistant together in one responsive website.

Instead of keeping plans, revision notes, and project checklists in separate places, use TaskCraft to map out what you want to learn or build, break it into phases and tasks, and track your progress from the dashboard. It is designed for students and independent learners, and can also be used to organize personal projects.

The front end is a single-page app built with HTML, CSS, and browser JavaScript in [index.html](./index.html). It works locally in your browser. Supabase Auth, Postgres with Row Level Security, and a Supabase Edge Function are included as backend setup scaffolding; the current interface does not expose account sign-in, so new users cannot sign in or sync data from the website.

## Features

- **One study and project workspace:** Keep learning plans, project tasks, revision cards, and progress together.
- Dashboard with task totals, completion progress, saved roadmap phases, flashcard totals, a daily streak, and a seven-day completion count.
- Task creation, completion, deletion, priorities, due dates, categories, search, and filters.
- AI learning roadmaps with flowchart and step-by-step views, phase details, prerequisites and tools, and phase-to-task import.
- Flashcards with question/answer flipping, manual creation, and optional AI-generated decks.
- A contextual study and planner assistant.
- Browser-local storage for tasks, roadmaps, and flashcards.
- Offline sample roadmaps, study guidance, and flashcard prompts when cloud AI is not connected. These are labelled as samples; they are not generated by an AI model.
- Responsive layout for mobile and desktop.

## How it works

1. Add a study goal or project tasks, then set priorities and due dates to decide what needs attention.
2. Generate a roadmap for a topic, explore its phases, and add phase action items to your task list.
3. Create or review flashcards to practise recalling key ideas.
4. Use the dashboard to see open and completed work, completion progress, and recent activity.
5. Your workspace is saved locally in this browser. The included Supabase backend is not currently connected to an account sign-in interface.

When Gemini is not configured, TaskCraft can provide clearly labelled sample roadmaps, flashcards, and study guidance. This fallback works without AI and does not claim that sample content was AI-generated.

## Run locally

You can open `index.html` directly for local-only features. To use Supabase Auth and its Edge Function locally, serve the folder over HTTP instead; from this folder run:

```powershell
py -m http.server 8000
```

Then open <http://localhost:8000>. The Supabase JavaScript client is loaded from a CDN, so an internet connection is needed.

## Connect Supabase and Gemini

Follow [`supabase/SETUP.md`](./supabase/SETUP.md):

1. Run [`supabase/schema.sql`](./supabase/schema.sql) in the Supabase SQL Editor.
2. Replace `SUPABASE_URL` and `SUPABASE_ANON_KEY` in `index.html` with your Supabase Project URL and browser-safe publishable/anon key.
3. Deploy `supabase/functions/ai-assistant` with the Supabase CLI and set `GEMINI_API_KEY` as a server-side secret.
4. Enable Email Auth and configure the correct local/hosted site URLs in Supabase Auth.

Never put a Supabase service-role key or Gemini API key in `index.html` or any public GitHub file. The included database tables have user-scoped RLS policies. The current website UI does not provide sign-in, and local browser records are not uploaded to Supabase.

## Publish on GitHub Pages

This folder is the website project root. From this folder, create a repository on GitHub, then run:

```powershell
git init -b main
git add .
git commit -m "Add TaskCraft study planner"
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

Replace the example remote URL with your new GitHub repository URL. Enable Pages in **Settings → Pages**, choosing **GitHub Actions** as the build/deploy source. The included workflow publishes `index.html` on pushes to `main`.

Supabase and Gemini remain separate hosted services; GitHub Pages only serves the front end. Set the published GitHub Pages URL in Supabase **Authentication → URL Configuration**. For local development, also allow `http://localhost:8000`.
